┌──────────────────────────────────────────────────────────────────────┐
│ WHAT IT DOES                                                          │
└──────────────────────────────────────────────────────────────────────┘
  Caches OCR results by tracker ID to avoid processing same plate 
  multiple times → 20-30% FPS improvement

┌──────────────────────────────────────────────────────────────────────┐
│ KEY SETTINGS (in inout_event.py)                                     │
└──────────────────────────────────────────────────────────────────────┘
  ENABLE_OCR_CACHE         = True    # Enable caching
  OCR_CACHE_MIN_CONFIDENCE = 0.85    # Min confidence to use cache
  OCR_CACHE_MAX_AGE_FRAMES = 180     # Cache lifetime (6s at 30fps)

┌──────────────────────────────────────────────────────────────────────┐
│ QUICK TUNING                                                          │
└──────────────────────────────────────────────────────────────────────┘
  
  PROBLEM: Low hit rate (<30%)
  SOLUTION: OCR_CACHE_MIN_CONFIDENCE = 0.75  # Lower threshold
  
  PROBLEM: Wrong plates logged
  SOLUTION: OCR_CACHE_MIN_CONFIDENCE = 0.90  # Higher threshold
  
  PROBLEM: No performance gain
  SOLUTION: Check if OCR is producing valid plates with suffix

┌──────────────────────────────────────────────────────────────────────┐
│ HOW IT WORKS                                                          │
└──────────────────────────────────────────────────────────────────────┘
  Frame 1: Detect plate → Run OCR (100ms) → Cache result
  Frame 2: Detect plate → Check cache → Use cached (0ms) ✓ Saved 100ms!
  Frame 3: Detect plate → Check cache → Use cached (0ms) ✓ Saved 100ms!
  ...
  Result: 93% reduction in OCR time for tracked vehicles

┌──────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                       │
└──────────────────────────────────────────────────────────────────────┘
  
  Q: Is caching affecting accuracy?
  A: No, only high-confidence results (with valid suffix) are cached
  
  Q: How do I disable it?
  A: Set ENABLE_OCR_CACHE = False
  
  Q: Cache growing too large?
  A: Reduce OCR_CACHE_MAX_AGE_FRAMES to 120 or 90
  
  Q: Not seeing performance gain?
  A: Check hit rate - if low, lower OCR_CACHE_MIN_CONFIDENCE
